红石镇 社区组织

Duties, requirements and active members.

// 部门职能

管理部

Admin

统理镇务、审核申请、维护秩序，是红石镇正常运转的基石。

"万物秩序的终点。"

建筑部

Builder

负责镇内建筑规划与审批，构筑红石镇的每一寸风景。

"做为创世神，手握真理（WE 和 AX），世界的缔造者，让世间万物重构成最美妙的样子。"

研究部

R & D

红石镇技术研发团队，让红石镇的技术始终走在服务器最前列。

"把幻想变为可能，把可能变为现实。"

废物部

Fun

聊天吹水、活跃气氛，是镇上的欢乐源泉。

"我直接耍起嘛。"

// 加入条件

您如果对某一个部门感兴趣，可以随时根据此手册的流程申请加入某个部门。

申请前提条件

  1. 您是红石镇的成员
  2. 您有红石镇的地皮权限
  3. 您已加入红石镇的 QQ 群

管理部

  1. 加入红石镇超过 3 年时间
  2. 不会向外界透露内部信息
  3. 管理部成员全票通过

建筑部

  1. 准备好您的建筑，并向管理部或建筑部规划师提交申请
  2. 由管理部或规划师审核您的建筑

研究部

  1. 自身红石技术过硬，或很有天赋，或被任意现任研究员看重并内推
  2. 性格品德优秀，无严重案底
  3. 观察期内表现良好
  4. 现任所有研究员进行投票且全票通过

废物部

  1. 红石镇管理部不拒绝（包括同意和无感）
  2. 向部长瓶子（bottle）提交申请
